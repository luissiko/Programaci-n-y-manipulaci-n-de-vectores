# Programación y Manipulación de Vectores en C#

Proyecto académico desarrollado en **C#** para la asignatura de **Programación Orientada a Objetos (POO)**.

El programa permite trabajar de manera interactiva con vectores de caracteres mediante una aplicación de consola, realizando operaciones de generación, modificación, ordenamiento y redimensionamiento.

## Descripción

El programa solicita al usuario definir el tamaño inicial de un vector, permitiendo un máximo de 99 posiciones.

Posteriormente, genera automáticamente letras minúsculas aleatorias que son almacenadas dentro del vector.

A partir del vector generado, el usuario puede modificar elementos, visualizar sus posiciones, ordenar los caracteres y aumentar dinámicamente el tamaño del arreglo.

## Funcionalidades

- Definir el tamaño inicial del vector.
- Validar tamaños entre 1 y 99 posiciones.
- Generar letras minúsculas aleatorias.
- Mostrar los elementos y posiciones del vector.
- Seleccionar un elemento mediante su índice.
- Reemplazar un carácter del vector.
- Validar las entradas proporcionadas por el usuario.
- Ordenar el vector de forma ascendente.
- Ordenar el vector de forma descendente.
- Aumentar dinámicamente el tamaño del vector.
- Conservar los elementos existentes al ampliar el vector.
- Generar nuevos caracteres para las posiciones añadidas.
- Repetir las operaciones o finalizar el programa.
